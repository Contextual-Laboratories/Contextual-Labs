# Security Policy

If you find a security vulnerability in the Contextual CLI, MCP server, or
any Contextual Labs product, please report it privately — do not open a
public GitHub issue.

**Report to:** security@contextuallabs.dev

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce (proof-of-concept code or commands, if you have them)
- The affected version(s)

We'll acknowledge your report and follow up as we investigate. Please give
us a reasonable window to address the issue before any public disclosure.

This policy covers the Contextual engine (CLI/MCP server) and the web
dashboard/backend, even though their source lives in private repositories —
this is the public entry point for reporting.
