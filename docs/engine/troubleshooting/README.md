# engine / troubleshooting

Symptom-indexed, not task-indexed: find your entry by what you're
seeing, not by what you already know you're trying to do. Each entry is
symptom → what it actually means → likely cause → fix, modeled on a
standard error-code reference plus an incident runbook.

`entity-not-found.md` and `workspace-not-connecting.md` are authored.
More entries (mined directly from real failure modes in the CLI/daemon/
MCP code, not guessed) land in a later pass.
