<Callout variant="tldr">
`contextual version` prints the currently installed version of
Contextual. No arguments.
</Callout>

## Usage

```
contextual version
```

<Terminal lines={[
  {command: "contextual version"},
  {output: "contextual 0.9.17", muted: true}
]} />
