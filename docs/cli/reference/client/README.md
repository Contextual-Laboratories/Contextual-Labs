# client commands

Configure, list, and remove AI-client MCP integrations. See [integrations/](../../../integrations/README.md) for the per-client setup guides these commands support.

`client` (connect one client to the current workspace), `client rm`
(disconnect it), `client list` (see what's connected, device-wide or
scoped to the current workspace), `client config` (edit the global
access-policy file directly).
