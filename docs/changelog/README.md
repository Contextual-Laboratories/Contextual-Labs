# Changelog

Release notes for Contextual, starting at v1.0.0 — everything before
launch was pre-release churn, not part of the public story.

Each release is one YAML file, tagged by domain (`engine` or
`website`) and, for an engine release, the PyPI version it shipped in.
This page is intro copy only, hand-authored — the version list itself
is generated separately from those files, not from this page.
