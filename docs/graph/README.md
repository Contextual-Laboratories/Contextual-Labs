# Knowledge graph

How entities and relationships get resolved, and how confident the engine is about each one.

- `graph/explanation/the-knowledge-graph` — what gets extracted, and the
  resolution strategies that go beyond a plain AST parse.
- `graph/explanation/entity-and-predicate-taxonomy` — the full 15-type,
  18-predicate closed vocabulary.
- `graph/explanation/confidence-tiers-and-resolution` — what `high` /
  `moderate` / `low` / `speculative` mean on a graph edge.
- `graph/reference/graph-schema-reference` — the `entities`/`triples`
  table fields, and the same taxonomy as a lookup table.
- `graph/how-to/read-a-graph-traversal-result` — reading `graph_traverse`
  and `graph_find_path` output.
- `graph/how-to/interpret-a-blast-radius-report` — reading `graph_impact`
  output before a rename or delete.
