# Support

**GitHub Issues is the official support channel for Contextual** — bug
reports, docs feedback, and feature requests all go through
[Issues](../../issues/new/choose). Pick the template that matches; each one
routes into a small `type:`/`area:` label taxonomy so issues stay
searchable and triage-able.

**Typical first response: 1–3 business days.** That's an acknowledgment
and a label, not a fix — this is a solo-maintained project, so full
resolution timelines vary with severity and complexity. If it's been
longer than that with no response, a bump comment is always fair game.

Every new issue also gets an automatic welcome comment confirming it's
been received — if you don't see one within a few minutes of opening,
something's probably wrong on our end, not yours.

## Security vulnerabilities

Don't open a public issue for a security vulnerability. See
[`SECURITY.md`](SECURITY.md) for the private reporting channel.

## Everything else

For anything that isn't a bug, docs issue, or feature request —
`team@contextuallabs.dev`.
